# Architecture — Expanse Tracker

## Tech Stack

| Layer | Technology |
|---|---|
| Runtime | Node.js 24, TypeScript 5.9 |
| Frontend | React 19, Vite, Tailwind CSS, shadcn/ui, Wouter (routing), TanStack Query v5 |
| Backend | Express 5, Pino (logging), Zod (validation) |
| Database | PostgreSQL 16 (Replit managed) via Drizzle ORM |
| Auth | **Clerk** (Replit-managed) — session cookies for web, Google OAuth + Email OTP out of the box; local `users` table JIT-provisioned on first sign-in |
| API contract | OpenAPI 3.1 (`lib/api-spec/openapi.yaml`), client generated by Orval |
| Package manager | pnpm workspaces (monorepo) |

## Database Schema

> All monetary values are in **BDT (৳)**. All timestamps include timezone.

### `users`
| Column | Type | Notes |
|---|---|---|
| id | serial PK | |
| name | text NOT NULL | |
| email | text NOT NULL UNIQUE | |
| password_hash | text NOT NULL | bcrypt, cost 12 |
| phone | text nullable | |
| account_type | enum(`Single Person`, `Family`) | default `Single Person` |
| role | enum(`user`, `admin`) | default `user` |
| subscription_plan | text | default `free`; stores plan slug (e.g. `monthly`, `yearly`) |
| subscription_expiry | timestamptz nullable | set on upgrade |
| status | enum(`active`, `suspended`) | default `active` |
| created_at | timestamptz | auto |

### `expenses`
| Column | Type | Notes |
|---|---|---|
| id | serial PK | |
| user_id | int nullable FK → users.id | nullable for backward compat |
| title | text NOT NULL | 1–120 chars |
| amount | numeric(12,2) NOT NULL | BDT, must be > 0 |
| category | text NOT NULL | dynamic; driven by `categories` table |
| date | date NOT NULL | ISO `YYYY-MM-DD` |
| type | enum(`recurring`, `one-time`) | |
| created_at | timestamptz | auto |

### `categories`
| Column | Type | Notes |
|---|---|---|
| id | serial PK | |
| name | text NOT NULL UNIQUE | display name, e.g. `Utilities` |
| icon | text nullable | emoji, e.g. `⚡` |
| is_active | boolean | default true; controls availability in expense form |
| sort_order | int | default 0; controls display order |
| created_at | timestamptz | auto |

**Default seed:** Utilities ⚡ (0), Bazar 🛒 (1), One-Time 🎯 (2)

### `pricing_plans`
| Column | Type | Notes |
|---|---|---|
| id | serial PK | |
| plan_name | text NOT NULL | display name, e.g. `Monthly` |
| slug | text NOT NULL UNIQUE | machine key stored in `users.subscription_plan` |
| price | numeric(10,2) NOT NULL | BDT |
| duration_in_months | int NOT NULL | used to calculate `subscription_expiry` |
| features | text[] | bullet points shown on pricing page |
| is_active | boolean | default true |
| sort_order | int | default 0 |
| created_at | timestamptz | auto |

**Default seed:** Monthly (slug=`monthly`, ৳100, 1 month), Yearly (slug=`yearly`, ৳500, 12 months)

### `system_settings`
| Column | Type | Notes |
|---|---|---|
| id | serial PK | always exactly 1 row |
| announcement_text | text | shown as banner on dashboard when active |
| is_announcement_active | boolean | default false |
| allow_registrations | boolean | default true; blocks `POST /api/auth/register` when false |
| updated_at | timestamptz | auto |

## API Routes Summary

### Public (no auth)
- `GET /api/healthz`
- `POST /api/auth/register` — respects `allow_registrations` setting
- `POST /api/auth/login`
- `GET /api/categories`
- `GET /api/pricing-plans`
- `GET /api/settings`

### Authenticated (Bearer JWT)
- `GET|PATCH /api/user/profile`
- `GET|POST|PATCH|DELETE /api/expenses`
- `GET /api/expenses/summary/monthly?month=YYYY-MM`
- `POST /api/subscription/upgrade` — body: `{ planId: number }`

### Admin only (Bearer JWT + role=admin)
- `GET /api/admin/stats`
- `GET /api/admin/users`
- `POST /api/admin/user/:id/toggle-status`
- `POST /api/admin/user/:id/upgrade`
- `GET|POST|PATCH|DELETE /api/admin/categories`
- `GET|POST|PATCH|DELETE /api/admin/pricing-plans`
- `GET|PATCH /api/admin/settings`

## Key Design Decisions

- **Clerk, not custom JWT.** Replit-managed Clerk tenant handles all auth (Google OAuth, Email OTP, Email+Password). Session cookies are issued by Clerk and sent automatically with same-origin API calls — no Bearer tokens, no `localStorage` token management.
- **Expense category as `text`.** Originally a PostgreSQL enum; migrated to plain text so the admin CMS can manage categories dynamically without schema changes.
- **`subscription_plan` as `text`.** Stores the plan's `slug` (e.g. `"monthly"`). Decoupled from any enum so new plans added via CMS work immediately.
- **JIT local user provisioning.** On first authenticated request, `requireAuth` middleware calls Clerk to get the user's name + email, then upserts a row in `users` (matching by `clerkUserId`, falling back to email for JWT-era accounts). `req.localUser` is attached for all downstream handlers — no extra DB query per route.
- **OpenAPI is the contract.** All expense endpoints are spec-first; client hooks and Zod schemas are code-generated via Orval. Auth/CMS/admin endpoints are hand-rolled (plain `fetch`) since they change frequently.
- **Single-row `system_settings`.** Enforced at the application level; `ensureSettings()` helper creates the row on first access.
